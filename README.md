# Japan Births Predictor

A simple Flask web app that serves a linear regression model trained on the
[Japan Birth Statistics 1899–2023](https://www.kaggle.com/datasets/hideos/japan-birth-statistics-18992023)
dataset. Given a year, it predicts the number of births.

## Project structure

```
.
├── app.py              # Flask app (serves predictions)
├── train.py             # Downloads dataset via kagglehub and trains the model
├── model/
│   └── birth_model.joblib   # Trained model (generated by train.py)
├── requirements.txt
├── render.yaml           # Render.com deploy config
├── LICENSE
└── README.md
```

## Setup (local)

1. Clone the repo and install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Set up Kaggle API credentials so `kagglehub` can download the dataset
   (place `kaggle.json` in `~/.kaggle/`, or run `kagglehub.login()`).
   See [Kaggle API docs](https://github.com/Kaggle/kaggle-api#api-credentials).

3. Train the model:
   ```bash
   python train.py
   ```
   This downloads the dataset, trains a linear regression model, and saves
   it to `model/birth_model.joblib`. Check the printed column names — if
   `train.py` picks the wrong columns, adjust the `year_col` / `birth_col`
   detection near the top of the script.

4. Run the app locally:
   ```bash
   python app.py
   ```
   Visit `http://localhost:5000`.

## API usage

```bash
curl "http://localhost:5000/predict?year=2025"
```

Response:
```json
{"year": 2025, "predicted_births": 812345}
```

## Deploying to Render.com

1. Push this repo to GitHub, **including the trained `model/birth_model.joblib`
   file** (Render's build step does not run `train.py`, so the model must
   already be committed).
2. On [Render.com](https://render.com), create a new **Web Service** and
   connect this repository.
3. Render will pick up `render.yaml` automatically, or set manually:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn app:app`
4. Deploy. Render will give you a live URL such as
   `https://japan-births-predictor.onrender.com`.
